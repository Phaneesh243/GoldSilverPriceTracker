# Metals chart workspace — 2026-09-09

## Why charts were missing

`getMetalHistory` deliberately returns no observations because the application has no approved INR historical feed. The previous detail UI also hid its chart inside a collapsed disclosure. Current snapshots cannot supply historical candles.

## Implemented

- Visible advanced chart on `/metals` and the four metal detail pages; lazy connection when the panel approaches the viewport.
- TradingView's hosted Advanced Chart with default candlesticks, line/area controls, 15m/1h/4h/daily/weekly intervals, native date ranges, pan/zoom, indicators, comparison, drawing toolbar and provider image capture.
- Fullscreen enter/exit, reload and a permanent external full-chart fallback. Toolbar is compact on mobile; the full side drawing toolbar is enabled on larger screens.
- Shared Dashboard/Stocks light/dark theme restored. Widget theme follows the same preference.
- The free widget retains TradingView branding and attribution. No subscription, API key, paid library, custom data scraping or subscriber messages are involved.

## Instrument separation

| Metal | Hosted chart | Native unit |
| --- | --- | --- |
| Gold | OANDA:XAUUSD | USD / troy oz |
| Silver | OANDA:XAGUSD | USD / troy oz |
| Platinum | OANDA:XPTUSD | USD / troy oz |
| Copper | OANDA:XCUUSD | USD / lb |

These are international provider instruments, not Indian retail quotations. They are not the same feed as the existing Gold API × daily FX INR cards. No claim of Indian exchange, retail, physical-product or scrap history is made. Provider timestamps, sessions, delays and coverage remain visible inside the hosted chart. An iframe load is not treated as proof that a market is live.

INR historical tables, monthly/yearly calculations and data export remain unavailable until permitted historical observations and matching historical FX are connected. TradingView widget data is not extracted or saved in the application. Custom Pine scripts, strategy backtests, persistent drawing/account layouts and guaranteed exchange coverage are not included.

## Security and privacy

- `next.config.ts` allows only `https://www.tradingview-widget.com` as the added frame origin. Existing ad origins remain conditional. No script-src relaxation, third-party first-party JavaScript, browser security flags or extensions were added.
- The hosted URL follows the iframe generated by TradingView's official Advanced Chart embed. All instruments, styles and intervals are allowlisted. No account details, calculator inputs, page URL or current query string are passed in widget configuration. The iframe uses `referrerPolicy="no-referrer"`.
- The browser connects directly to the provider, which can see its IP address. The chart includes an external-service disclosure and TradingView privacy link. No third-party account login is performed by this application.
- External blockers and symbol restrictions can still prevent the chart from rendering. Reload and Open full chart remain available. A slow-load notice is shown; no substitute price history is generated.
